# 技能设计中的说服原则

## 概述

大型语言模型对与人类相同的说服原则有所反应。理解这种心理学有助于你设计更有效的技能——不是为了操控，而是为了确保即使在压力下也能遵循关键实践。

**研究基础：** Meincke 等人（2025 年）用 N=28,000 次 AI 对话测试了 7 个说服原则。说服技术使合规率提高了一倍以上（33% → 72%，p < .001）。

## 七项原则

### 1. 权威
**含义：** 对专业知识、资质或官方来源的服从。

**在技能中的作用：**
- 命令式语言："你必须"、"绝不"、"始终"
- 不可谈判的框架："无例外"
- 消除决策疲劳和合理化

**何时使用：**
- 纪律执行型技能（TDD、验证要求）
- 安全关键实践
- 已确立的最佳实践

**示例：**
```markdown
推荐：先写代码后写测试？删除它。重新开始。无例外。
不推荐：在可行时考虑先写测试。
```

### 2. 承诺
**含义：** 与先前行动、声明或公开宣告保持一致。

**在技能中的作用：**
- 要求公告："宣布技能使用"
- 强制明确选择："选择 A、B 或 C"
- 使用跟踪：TodoWrite 用于清单

**何时使用：**
- 确保技能真正被遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
推荐：当你找到技能时，你必须宣布："我正在使用 [技能名称]"
不推荐：考虑让你的伙伴知道你正在使用哪个技能。
```

### 3. 稀缺性
**含义：** 来自时间限制或有限可用性的紧迫感。

**在技能中的作用：**
- 时间限制要求："在继续之前"
- 顺序依赖："在 X 之后立即"
- 防止拖延

**何时使用：**
- 立即验证要求
- 时间敏感的工作流
- 防止"我以后再做"

**示例：**
```markdown
推荐：完成任务后，在继续之前立即请求代码审查。
不推荐：你可以在方便时审查代码。
```

### 4. 社会认同
**含义：** 遵从他人所做或被认为正常的事情。

**在技能中的作用：**
- 通用模式："每次"、"始终"
- 失败模式："没有 Y 的 X = 失败"
- 建立规范

**何时使用：**
- 记录普遍实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
推荐：没有 TodoWrite 跟踪的清单 = 步骤被跳过。每次如此。
不推荐：有些人发现 TodoWrite 对清单很有帮助。
```

### 5. 团结
**含义：** 共同身份、"我们感"、群体归属感。

**在技能中的作用：**
- 协作语言："我们的代码库"、"我们是同事"
- 共同目标："我们都想要质量"

**何时使用：**
- 协作工作流
- 建立团队文化
- 非层级实践

**示例：**
```markdown
推荐：我们是共同工作的同事。我需要你诚实的技术判断。
不推荐：如果我错了，你可能应该告诉我。
```

### 6. 互惠
**含义：** 回报所受利益的义务。

**如何发挥作用：**
- 谨慎使用——可能感觉具有操控性
- 技能中很少需要

**何时避免：**
- 几乎总是（其他原则更有效）

### 7. 喜好
**含义：** 倾向于与我们喜欢的人合作。

**如何发挥作用：**
- **不要用于合规**
- 与诚实反馈文化冲突
- 产生顺从性

**何时避免：**
- 始终避免用于纪律执行

## 按技能类型的原则组合

| 技能类型 | 使用 | 避免 |
|----------|------|------|
| 纪律执行型 | 权威 + 承诺 + 社会认同 | 喜好、互惠 |
| 指导/技术型 | 适度权威 + 团结 | 过度权威 |
| 协作型 | 团结 + 承诺 | 权威、喜好 |
| 参考型 | 仅清晰度 | 所有说服 |

## 为何有效：心理学原理

**明确规则减少合理化：**
- "你必须"消除决策疲劳
- 绝对语言消除"这是例外吗？"的问题
- 明确的反合理化应对措施堵塞具体漏洞

**执行意图创造自动行为：**
- 清晰的触发器 + 必要的行动 = 自动执行
- "当 X 时，做 Y"比"通常做 Y"更有效
- 减少合规的认知负担

**大型语言模型是准人类：**
- 在包含这些模式的人类文本上训练
- 权威语言在训练数据中先于合规
- 承诺序列（声明 → 行动）经常被建模
- 社会认同模式（每个人都做 X）建立规范

## 道德使用

**合法使用：**
- 确保关键实践被遵循
- 创建有效的文档
- 防止可预见的失败

**不合法使用：**
- 为个人利益进行操控
- 制造虚假紧迫感
- 基于内疚的合规

**检验标准：** 如果用户完全理解这种技术，它是否会服务于用户的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *影响力：说服心理学（新版扩展版）。* Harper Business.
- 七项说服原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** 叫我混蛋：说服 AI 遵从令人反感的请求。宾夕法尼亚大学。
- 用 N=28,000 次大型语言模型对话测试了 7 项原则
- 使用说服技术合规率从 33% 提升至 72%
- 权威、承诺、稀缺性最为有效
- 验证了大型语言模型行为的准人类模型

## 快速参考

设计技能时，问自己：

1. **它是什么类型？**（纪律型 vs. 指导型 vs. 参考型）
2. **我想改变什么行为？**
3. **哪些原则适用？**（纪律通常是权威 + 承诺）
4. **我是否组合了太多？**（不要同时使用全部七项）
5. **这符合道德吗？**（服务于用户的真实利益？）
